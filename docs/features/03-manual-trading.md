# 03. 수동 매매

**상태**: 설계완료 · 구현 전
**화면 ID**: SCR-03
**의존성**: `01-auth` (초기 시드머니로 즉시 매매 가능). 지정가 주문의 체결은 [09-execution-engine.md](09-execution-engine.md)의 체결 엔진을 이 기능과 함께 구현한다.
**연관 문서**: [00-overview.md](../00-overview.md) 5장(데이터 모델 확정 지점), 6장 원칙 4(코인 단위 잠금), [09-execution-engine.md](09-execution-engine.md)

---

## 1. 목적

코인 조회·차트·호가 확인 및 지정가/시장가 주문. **여기서 확정되는 `orders`/`holdings` 데이터 모델과 주문 실행 로직은 07(자동매매)이 그대로 재사용**하므로, 이 기능의 설계 품질이 이후 자동매매 구현 난이도를 좌우한다.

레이아웃: 4컬럼 — 코인 목록(200px) / 시세·차트·미체결 주문 / 호가창(180px) / 주문 패널·잔고(220px)

## 2. 화면 구성

### 2-A. 1열 — 코인 목록

| 컴포넌트 | 유형 | 설명 |
|---|---|---|
| 코인 검색 박스 | Input (search) | 코인명/심볼 실시간 필터링 |
| 코인 목록 행 | List Item | 코인명(심볼)+현재가+등락률. 선택 행 배경 강조. **자동매매 운용 중인 코인은 "자동" 배지 표시** (07 완료 후 연동) |

### 2-B. 2열 — 시세·차트·미체결

| 컴포넌트 | 유형 | 설명 |
|---|---|---|
| 현재가 대형 텍스트 | Price Display | 등락률 색상 표시 |
| 고가·저가·거래량 | Info Row | 당일 고가/저가, 24H 거래량 |
| 시간대 탭 | Tab Group | 1분/10분/30분/1시간/일 |
| 캔들 차트 | Candlestick Chart | OHLCV 툴팁 |
| 미체결 주문 목록 | List | 취소 버튼 (확인 없이 즉시 처리) |

### 2-C. 3열 — 호가창

매도 호가 10단(파랑) / 현재가 / 매수 호가 10단(빨강). 클릭 시 주문가격 자동 입력.

### 2-D. 4열 — 주문 패널 · 잔고

| 컴포넌트 | 유형 | 설명 |
|---|---|---|
| 매수/매도 탭 | Tab | 매수(빨강)/매도(파랑) |
| 주문 유형 탭 | Tab | 지정가/시장가 (시장가 시 가격 입력 비활성) |
| 주문가격/수량 입력 | Input (number) | 콤마 포매팅 |
| 비율 버튼 | Button Group | 10/25/50/75/최대 |
| 주문금액 자동계산 | Read-only | 가격×수량 |
| 매수/매도 버튼 | Button (Primary) | 잔고 부족 시 비활성화 |
| **잠금 배너** (신규) | Alert Banner | 선택 코인이 자동매매 운용 중이면 주문 영역 전체 비활성화 + "이 코인은 자동매매(전략명)가 운용 중입니다. [자동매매 화면으로 이동]" 표시. 07 완료 전까지는 항상 숨김 상태로 유지 |
| 보유 원화/코인 표시 | Info Row | 실시간 |

## 5. 데이터 모델 (확정 — 이후 기능 공유)

> 전체 스키마의 기준은 [01-erd.md](../01-erd.md)다. 아래는 이 기능 관점의 발췌.

```
orders
  id (PK)
  user_id (FK)
  coin_symbol
  side               -- buy | sell
  order_type         -- limit | market
  price              -- market 주문은 체결가 기록
  quantity
  status             -- pending | filled | canceled  (전이는 09-execution-engine.md 체결 엔진이 담당)
  source             -- manual | auto   (07에서 auto 사용)
  strategy_slot_id   -- FK, nullable (07에서 사용)
  realized_profit    -- nullable, sell 체결 시 holdings.avg_buy_price 기준 손익 기록 (08 월별 수익 리포트용)
  fee                -- 체결 수수료(원화), pending 동안 0. 계산 규칙 01-erd.md 3.2절
  created_at
  filled_at

holdings
  user_id (FK)
  coin_symbol
  quantity
  avg_buy_price
  PRIMARY KEY (user_id, coin_symbol)
```

## 6. API 엔드포인트 (초안)

| Method | Path | 설명 |
|---|---|---|
| GET | `/api/coins` | 코인 목록 + 현재가/등락률 |
| GET | `/api/coins/{symbol}/candles?interval=` | 캔들 데이터 |
| WS | `/ws/orderbook/{symbol}` | 호가 실시간 구독. 데이터량이 커서 전체 상시 구독 대상(00-overview 3장의 시세 캐시)에 포함하지 않고, 사용자가 이 화면에서 보고 있는 심볼만 온디맨드로 Upbit에 구독 요청 — 화면을 벗어나거나 다른 코인을 선택하면 해제 |
| POST | `/api/orders` | 주문 생성 (지정가/시장가 공통 — 07 자동매매도 이 로직을 내부 호출로 재사용). 시장가는 즉시, 지정가는 `pending`으로 저장 후 [09-execution-engine.md](09-execution-engine.md) 체결 엔진이 체결 |
| DELETE | `/api/orders/{id}` | 미체결 취소 |
| GET | `/api/orders?status=pending` | 미체결 목록 |
| GET | `/api/coins/{symbol}/lock-status` | (07 완료 후 추가) 자동매매 잠금 여부 |
