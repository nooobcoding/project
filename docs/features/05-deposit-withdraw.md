# 05. 입출금

**상태**: 설계완료 · 구현 전
**화면 ID**: SCR-07
**의존성**: `03-manual-trading` (`balances` 잔고 모델이 여기서 이미 확정됨 — 이 기능은 그 위에 충전/차감만 추가)
**연관 문서**: [00-overview.md](../00-overview.md) 5장(데이터 모델)

---

## 1. 목적

가상 원화 입금/출금 및 내역 조회. 다른 연산 없이 사용자 입력을 잔고에 그대로 반영하는 단순 CRUD 기능.

레이아웃: 2컬럼 — 좌(340px): 잔고 + 입금·출금 폼 / 우: 입출금 내역

---

## 2. 화면 구성

### 2-A. 좌측 — 입금·출금

| 컴포넌트 | 유형 | 설명 |
|---|---|---|
| 가상 원화 잔고 카드 | Balance Card | 현재 잔액, 처리 후 즉시 갱신 |
| 입금/출금 전환 탭 | Tab | 입금(녹색)/출금(빨강) |
| 금액 입력 필드 | Input (number) | 콤마 자동 포매팅 |
| 빠른 선택 버튼 | Button Grid | +10만/50만/100만/300만/500만/1,000만원, 클릭 시 누적 |
| **메모 입력** (신규) | Input (text, 선택) | 플레이스홀더 "예: 용돈 입금", 최대 30자. v1.0에서 내역 테이블에는 메모 컬럼이 있었으나 입력 UI가 누락되어 있던 것을 보완 |
| 처리 후 잔고 미리보기 | Preview Text | "입금 후 잔고: X원 → Y원" 실시간 계산 |
| 확인 버튼 | Button (Primary) | 입금: 녹색 / 출금: 빨강. 금액 미입력/0원 시 비활성화 |
| 출금 초과 경고 박스 | Warning Box | 출금 탭에서 항시 표시 |

### 2-B. 우측 — 입출금 내역

| 컴포넌트 | 유형 | 설명 |
|---|---|---|
| 유형 필터 칩 | Filter Chips | 전체/입금/출금 |
| 날짜 범위 필터 | Date Range Picker | - |
| 내역 목록 | Table | 유형 배지 / 금액(입금 +, 출금 -) / 처리 후 잔고 / 일시 / **메모** |
| 페이지네이션 | Pagination | 10건/페이지 |

## 3. 인터랙션 / 오류 처리

| 위치 | 이벤트 | 처리 |
|---|---|---|
| 빠른 선택 버튼 | Click | 기존 입력값에 누적 덧셈 (최대 한도 없음, 모의투자) |
| 확인 버튼 | Click | 유효성 검사 → `balances` 갱신 → 내역 목록 갱신 |

| 오류 상황 | 메시지 |
|---|---|
| 출금 금액 > 출금 가능액 | 출금 금액이 보유 잔고를 초과합니다. (자동매매에 배정된 금액이 있다면 이를 제외한 금액 기준) |
| 금액 0/음수 | 올바른 금액을 입력해주세요. (1원 이상) |

**"보유 잔고" 기준**: `balances.krw_balance` 전체가 아니라 **출금 가능액**([01-erd.md](../01-erd.md) 3.1절 — 가용 원화에서 활성 자동매매 슬롯에 배정된 금액까지 제외한 값)으로 검증한다. 미체결 지정가 매수 주문의 동결액뿐 아니라 07의 활성 슬롯이 앞으로 사용할 배정액까지 출금 가능액에서 빠지므로, 자동매매 운용 중에 그 배정액까지 출금해 슬롯의 매수가 계속 스킵되는 상황을 방지한다.

## 4. 데이터 모델

```
deposits_withdrawals
  id (PK)
  user_id (FK)
  type              -- deposit | withdraw
  amount
  balance_after
  memo              nullable, max 30자
  created_at
```

---

## 5. API 엔드포인트 (초안)

| Method | Path | 설명 |
|---|---|---|
| POST | `/api/wallet/deposit` | 입금 (`amount`, `memo`) |
| POST | `/api/wallet/withdraw` | 출금 (`amount`, `memo`) |
| GET | `/api/wallet/transactions?type=&start=&end=&page=` | 내역 조회 |
